# 🛍️ K-Store — متجر إلكتروني فاخر متنوع المنتجات

متجر إلكتروني احترافي وفخم مبني بـ **Next.js 14** مع قاعدة بيانات **SQLite**، يدعم آلاف المنتجات، ويحتوي على **ذكاء اصطناعي لإدخال المنتجات تلقائياً** من الصورة والوصف، و**لوحة تحكم كاملة للمالك**.

## ✨ المميزات

### واجهة المتجر (Storefront)
- تصميم فاخر بالألوان الداكنة واللمسات الذهبية، دعم عربي كامل (RTL)
- صفحة رئيسية أنيقة (Hero، الفئات، المنتجات المميزة، الأحدث، عروض)
- قائمة منتجات مع بحث، فلترة بالفئة والسعر، ترتيب، وترقيم صفحات (يدعم آلاف المنتجات)
- صفحة تفاصيل المنتج (معرض صور، تقييم، كمية، إضافة للسلة، شراء فوري، طلب واتساب)
- سلة تسوق محفوظة محلياً + صفحة دفع إلكتروني آمن (بطاقة)
- صفحة تأكيد الطلب وتتبعه
- رقم التواصل: **771717913**

### 🤖 الذكاء الاصطناعي لإدخال المنتجات
من لوحة التحكم: ارفع صورة المنتج + اكتب وصفاً بسيطاً → يولّد الـ AI تلقائياً:
- اسم المنتج الاحترافي
- الفئة المناسبة (من 13 فئة)
- السعر المقترح بالريال اليمني + سعر المقارنة
- الوصف التسويقي التفصيلي
- العلامة التجارية والوسوم ورمز SKU
- ثم راجع وعدّل أي حقل قبل الحفظ

> المحرك يعمل محلياً (بدون مفاتيح API خارجية) ويمكن استبداله بنموذج LLM خارجي بتعديل `lib/ai.js`.

### 🎛️ لوحة تحكم المالك
- تسجيل دخول آمن (JWT + كوكي httpOnly)
- نظرة عامة: الإيرادات، الطلبات، المنتجات، مبيعات اليوم، آخر الطلبات، توزيع الفئات
- إدارة المنتجات (بحث، تفعيل/إخفاء، تعديل، حذف)
- إضافة منتج بالذكاء الاصطناعي
- إدارة الطلبات (فلترة + تحديث الحالة: قيد المراجعة / مؤكد / تم الشحن / تم التوصيل / ملغي)
- إدارة الفئات (إضافة/تعديل/حذف مع رمز تعبيري ولون)
- إعدادات المتجر (الاسم، الهاتف، الشحن، الإعلان...)

## 🚀 التشغيل

```bash
npm install
npm run seed        # يزرع الفئات والمنتجات وحساب المالك والإعدادات
npm run dev         # http://localhost:3000
```

- المتجر: `/`
- لوحة التحكم: `/admin` (تُحوّل تلقائياً لتسجيل الدخول)

## 🏗️ البنية التقنية
| الجزء | التقنية |
|------|---------|
| الواجهة/الخادم | Next.js 14 (App Router) |
| التصميم | Tailwind CSS + خطوط Cairo/Tajawal |
| قاعدة البيانات | SQLite (better-sqlite3) |
| المصادقة | JWT + bcrypt |
| الذكاء الاصطناعي | محرك تحليل محلي (`lib/ai.js`) |

## 📁 أهم الملفات
- `lib/db.js` — طبقة قاعدة البيانات (المنتجات، الفئات، الطلبات، الإعدادات، المشرف)
- `lib/ai.js` — محرك توليد بيانات المنتج بالذكاء الاصطناعي
- `lib/seed.js` — بذرة البيانات الأولية
- `app/` — صفحات المتجر ولوحة التحكم ومسارات الـ API
- `components/` — المكوّنات المشتركة
